# Playwright Project

This is a minimal Playwright test scaffold.

Quick start:

```bash
cd playwright
npm install
npm run install:playwright
npm test
```

Commands:

- `npm test` — run tests (headless).
- `npm run test:headed` — run tests with headed browser.
- `npm run install:playwright` — install browser binaries required by Playwright.

Files:
- package.json — npm scripts and devDependencies
- playwright.config.js — Playwright test runner config
- tests/example.spec.js — example test
